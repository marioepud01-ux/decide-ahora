# Decide Ahora

**Herramienta gratuita en español para generar alternativas, comparar opciones y tomar decisiones con más claridad.**

👉 **Prueba la web:** https://decide-ahora.onrender.com/

## Qué puedes hacer

- Describir una decisión personal, laboral o cotidiana.
- Obtener sugerencias iniciales de alternativas relacionadas con el tema.
- Elegir qué priorizas: dinero, tiempo, tranquilidad o crecimiento.
- Comparar hasta cinco opciones según beneficio, coste/esfuerzo, riesgo y encaje con tus prioridades.
- Ver una recomendación orientativa, el ranking y un siguiente paso concreto.
- Guardar un historial local en tu navegador, copiar resultados y compartir la herramienta.

## Privacidad y transparencia

No requiere registro. El historial se guarda en el almacenamiento local del navegador y no se sincroniza entre dispositivos. Las sugerencias se generan mediante reglas temáticas y la comparación utiliza una puntuación transparente; la versión actual no se conecta a un modelo de IA.
